# Job Hunter AI Tool — Frontend

This repository contains the React + Vite frontend for the **Job Hunter AI Tool**.

The frontend allows users to enter job search information, upload resumes, communicate with the backend API, and view ranked job matches generated by the system.

The goal of the application is to provide a simple interface for submitting job search criteria and receiving relevant job recommendations powered by backend machine learning ranking.

---

# Overview

The frontend collects user input through a search form and sends requests to the backend API. The backend processes the request, applies ranking logic, and returns ranked job matches which are displayed in the user interface.

Users may also upload a resume file (**PDF** or **DOCX**). The resume is sent to the backend where text extraction and parsing occur to support job matching.

The application was built using:

- **React** for the component-based user interface
- **Vite** for fast builds and hot module replacement
- **Axios** for frontend–backend API communication
- **Vitest** and **React Testing Library** for frontend testing

---

# Features

- Search for jobs using:
  - Job title
  - Skills
  - Location
  - Years of experience
- Upload resumes in **PDF** or **DOCX** format
- Display ranked job matches returned from the backend
- Show loading states during requests
- Display error handling and empty states
- Automated frontend component testing

# Quick Start

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Create a `.env` file in the frontend root directory:

```txt
VITE_API_BASE_URL=http://127.0.0.1:8000
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local development URL, typically:

```txt
http://localhost:5173
```

The development server supports hot module replacement, meaning updates appear automatically when code changes are saved.

---

# Backend API Connection

The frontend communicates with the backend using **Axios**.

API requests are defined in:

```txt
src/services/api.js
```

The frontend sends requests to the backend for:

- `POST /search`
- `POST /upload-resume`

The backend base URL is configured using an environment variable.

Example:

```txt
VITE_API_BASE_URL=http://127.0.0.1:8000
```

If no environment variable is provided, the application defaults to:

```txt
http://127.0.0.1:8000
```

# Frontend Testing

The frontend includes automated tests built with **Vitest** and **React Testing Library**.

These tests simulate:

- User interactions
- Mocked API requests
- Loading states
- Error handling
- Rendered output

The backend server is not required for test execution.

The current test suite covers:

- `ResumeUpload.jsx`
- `SearchForm.jsx`
- `JobResults.jsx`

## Test Coverage

### ResumeUpload Tests

Verifies:

- Component rendering
- Upload validation
- PDF acceptance
- DOCX acceptance
- Invalid file rejection
- Successful upload preview display
- Upload failure handling

### SearchForm Tests

Verifies:

- Form rendering
- Input updates
- API request payload generation
- Loading state behavior
- Clearing old results and errors
- Error handling

### JobResults Tests

Verifies:

- Ranked results rendering
- Loading state display
- Error state display
- Initial empty state
- No-results state
- Job card rendering
- Matched skills display
- Jobs without skills showing `None`
